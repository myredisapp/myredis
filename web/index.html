Features

为日常 Redis 工作而生

从连接到编辑、从监控到备份，把高频操作都装进一个轻巧的桌面应用。

多连接管理

单机与集群模式随切随连，支持密码 / ACL 认证、只读保护与自定义 Key 分隔符；连接配置本地持久化，重启即用。

全类型 Key 编辑

String、Hash、List、Set、Zset 五大类型可视化浏览与编辑，TTL 一目了然，改完即存。

内置终端

不离开客户端直接执行 Redis 命令，命令转发至后端真实执行，输出与界面状态实时同步。

服务器监控

内存、连接数、Key 总数、磁盘占用等关键指标实时展示，服务器健康状态一眼可知。

安全浏览

基于 SCAN 游标分页加载 Key，拒绝 KEYS * 阻塞生产实例；只读连接为线上数据加一道保险。

导入 / 导出

Key 数据一键备份与迁移，配合通配符搜索精准圈定范围，环境间搬数据不再手忙脚乱。

Themes

五款四季主题，总有一片属于你的麦田

应用内置春分、立夏、初秋、深秋、冬至五款主题，深浅色兼备。本主页与应用同款——点击卡片即刻换装。
